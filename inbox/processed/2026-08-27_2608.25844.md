# Paper

## One-line Summary

複数の機械的売買主体が互いの価格インパクトを通じて
フィードバックループを形成する市場で、
注文そのものを直接観測できなくても、
既知の時間変動するgainから相互作用を推定する方法を提示する。

## Research Question

外部からのprobeや入力を観測できないclosed-loop systemで、
複数主体間のcouplingをoutputだけから識別できるか。

## Data

理論モデル + simulation。

実データcase studyとして
leveraged-fund rebalancingを使用。

daily fund disclosuresを
known time-varying gainとして利用。

## Methodology

Feedback matrix:

L_t = Φ diag(γ_t)

を仮定。

γ_t:
観測可能なtime-varying gain

Φ:
未知のcross-channel coupling

として、

既知gainの時間変化と
一時的price displacementのpartial reversalを利用して
couplingを識別する。

## Main Findings

- gainが時間変化するとcouplingを識別可能。
- gainがconstantの場合はcouplingとconfoundを分離できない。
- channelごとの単独monitoringではcross-channel feedbackを見逃す。
- feedback propagationはresolvent sensitivityで捉えられる。
- leveraged-fund rebalancingへ適用可能であることをcase studyで示した。

## Evidence

論文では、
individual loopのみをmonitorすると
cross-channel couplingによるstability riskを過小評価すると指摘。

既知gainの変化が
latent inputを直接観測できない状況での
identification resourceになる。

## Limitations

識別には重要な仮定がある。

- gainがconfoundと独立
- gainが十分時間変化する
- conditional orthogonality
- persistent excitation
- partial reversal structure

また、
95% nominal intervalに対しempirical coverageが90%で、
uniform / selection-robust inferenceは未解決。

## Interpretation

市場には、

「自分の判断で売買する主体」

だけでなく、

ETF / leveraged fund / liquidation / hedging / index rebalance

のように、
状態変数によって機械的に売買量が決まる主体が存在する。

そのgainが外部から観測可能なら、

Observed market response
×
Known participant exposure

から、
直接注文フローが完全に見えなくても
market-impact networkを逆算できる可能性がある。

これは市場参加者起点の取引戦略研究と親和性が高い。

## Potential Applications

- ETF rebalance impact
- leveraged token / leveraged fund flow
- liquidation feedback
- funding-driven positioning
- index rebalance
- cross-venue market impact
- oracle feedback

# Hypotheses

## Hypothesis 1

### Statement

Hyperliquidでも、
公開されたposition / OI / liquidation / funding等から
機械的売買gainのproxyを構築できれば、
cross-market feedbackを推定できる可能性がある。

### Mechanism

例:

Spot price movement
→ leveraged / hedged participant action
→ HL Perp order flow
→ HL price displacement
→ subsequent reversal

というfeedback pathを推定する。

### Supporting Evidence

このHyperliquidへの応用自体は論文には記載されていない。
本論文のidentification frameworkから導いたInference。

### Required Data

- spot return
- HL perp return
- OI
- funding
- liquidation
- aggressor flow
- order book
- participant exposure proxy
- market-hours indicator
- cross-venue prices

### Proposed Test

既知または高精度にproxy化できるparticipant gainをγ_tとして、

return_i,t+1
~ return_j,t × γ_j,t

に類するinteractionを推定し、
gain variationが大きい期間ほど
cross-market responseが強まるか検証する。
